# Security Policy

This project is a single, self-contained HTML file with **no backend, no network calls and no
data collection**. The attack surface is therefore very small.

## Reporting

If you find a security issue, email **sohilmomin2000@gmail.com**. Please do not open a public
issue for security problems.

## Scope notes

- No analytics, no telemetry, no cookies.
- All data is bundled in the file; the app never transmits anything.
- `localStorage` is used only for your own notes, shortlist, theme and preferences.
