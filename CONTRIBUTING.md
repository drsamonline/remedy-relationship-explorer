# Contributing

Thanks for your interest. A few ground rules keep this project honest and maintainable.

## The golden rule

**Do not invent homeopathic content.** This project only structures text that already exists in
public-domain sources. Every relationship, keynote and remedy name must trace back to a source
book. If you cannot cite it, do not add it.

## Ways to help

- **Report a data error** — a wrong relationship, a mangled remedy name, a missing keynote.
  Please include the remedy, the relationship, and the printed source line if you can.
- **Suggest an enhancement** — open an issue. Offline-only suggestions are especially welcome.
- **Improve the UI/UX** — accessibility, responsiveness, clarity.
- **Add a source** — a public-domain materia medica with structured "Relations" sections.

## Pull requests

1. Keep the app a **single self-contained `app.html`** — no build step, no external dependencies.
2. No network calls at runtime. Ever.
3. Match the existing code style (vanilla JS, no frameworks).
4. Describe what you changed and why, and cite your sources for any data change.
