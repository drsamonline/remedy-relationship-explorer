Homeopathic remedy relationships,
offline and on one page.

An interactive graph of complementary, antidotal, inimical and “compare” links — built from four public-domain materia medicas. No server, no account, no network.

▶ Open the app ⬇ Downloads (.exe / .apk) ★ GitHub

Built for study and reference

Everything a practitioner or student needs to trace how remedies relate — and nothing that needs a server.

◎

Focus view

One remedy at a time, its relationships on a ring, grouped and coloured by type. Click to re-centre; breadcrumbs retrace your path.

✳

Network view

The most-connected remedies as a force graph, with a detail slider and collision-aware layout so nothing overlaps.

🔍

Search by symptom

Full-text search scans keynotes too — “burning itching worse heat” finds Sulphur, Oenanthe, Selenium and more.

⇄

Compare & paths

Compare two remedies (shared / exclusive / overlap score), or find the shortest chain of relationships between any pair.

⚖

Provenance

Every relationship is tagged B / C / H by source, with a “corroborated only” filter for the links two or more books agree on.

🎓

Study tools

Full keynotes in a built-in reader, quiz mode, flashcards, a shortlist with private notes, Markdown notebook export, SVG/PNG export and a printable remedy sheet. A guided tutorial runs on first visit.

Offline by design

The application has no server, no backend and no network dependency — a design constraint, not a limitation.

One file

The whole app — code and data — is a single HTML document. Copy it to a USB stick and it still works.

No tracking

No analytics, no telemetry, no cookies, no accounts. Your notes stay in your browser's local storage.

Installable

Install it as a PWA, or use the Windows / Android builds. All three run entirely on-device.
